# 流形 FLUX

一件关于创造的流体互动作品。滚动让粒子从噪声过渡到双旋臂星盘，最后聚成「流形」二字。鼠标是引力场。

## 运行

```bash
npm install
npm run dev
```

打开 http://localhost:5173/

## 构建

```bash
npm run build     # 输出到 dist/
npm run preview   # 本地预览构建结果
```

`dist/` 是纯静态文件，可直接部署到任何静态托管。

## 操作

- **移动鼠标**：扰动粒子流，靠近文字时会像液体一样荡开
- **向下滚动**：经历五章诗句，从混沌走向秩序
- **点击左上「流形」或页尾提示**：回到噪声（顶部）

## 技术

- Vite + Three.js，无框架
- 粒子场：InstancedBufferGeometry，每个粒子是沿局部流场方向拉长的四边形，顶点着色器内混合「curl 噪声湍流」与「对数螺线星盘」
- 文字的粒子化：离屏 canvas 采样字形像素，映射为粒子目标点（「光」与「流形」）
- 后期：UnrealBloom + 自定义颗粒/暗角/轻微色差
- 无障碍：`prefers-reduced-motion` 下显示静态画面与 DOM 标题；WebGL 不可用时自动退回 CSS 海报与静态排版
- 性能：按帧率自适应减半粒子；移动端降低粒子数与泛光强度
